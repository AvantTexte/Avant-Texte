# Proyecto Liseur - Frances & GitHub Badges

Aplicacion web interactiva inspirada en Duolingo para aprender vocabulario en frances extraido del libro Pilote de guerre de Antoine de Saint-Exupery.

## Caracteristicas del Proyecto

- 1.024 Fichas por Capitulos: Vocabulario organizado desde el Chapitre I al Chapitre XXVIII.
- Citas Literales: Cada tarjeta incluye el pasaje exacto en frances y su traduccion en espanol.
- Audio en Frances: Pronunciacion automatica con sintesis de voz.
- Modo Quiz XP: Sistema de preguntas de opcion multiple, racha diaria y puntos de experiencia.
- Coautoria Git: Envios continuos con firmas de coautoria.
- DevOps & Triage Bot: Flujos automaticos de CI/CD, auditoria de seguridad y triage de issues.
